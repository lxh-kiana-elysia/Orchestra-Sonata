# 乐团鸣曲

> 一个《BanG Dream!》二次同人 × 《脑叶公司》式收容管理玩法的叙事驱动同人游戏（免费，Steam/Windows）。

**当前阶段：文档齐备（GDD v1.11 / 架构 v1.4 / FDD v2.8 / UI 规范 v1.4 / 手册 v3.7），Unity 工程已过 M1 数据层、M2 界面进行中** · 设计文档版本 **GDD v1.11**

## 这是什么？

玩家扮演一名**新手工作人员**——在一次大型联合演出中被时空裂缝卷入平行时空，来到一家同样名为 Ring 的公司并出任收容设施的管理者。

在这个空间里，乐队少女们的情感创伤会凝结成具象化的 **「情感异想体」**。玩家将以旁观引导者的身份，派遣以原著形象登场的乐队少女执行 **演奏 / 谈话 / 创作 / 比武** 等工作，收集能源（情感粒子）、安抚异想体、一步步揭晓它们背后**平行时空同位体**的故事——探寻相似而又不同的命运。

> 一句话：**用音乐与共感，收容那些"没能说出口的心事"。**

## 核心玩法

- **脑叶式日循环管理**：选派少女 → 对异想体执行工作 → 成功率判定 → 结果剧情 → 结算与成长 → 达标后进入下一天
- **四维属性养成**：血量 / 精神 / 演奏水平 / 共感（初始全 10，共享 1–120 等级制，I~EX）
- **4 种工作 × 4 条成长线一一映射**：演奏→演奏水平、谈话→精神、创作→共感、比武→血量
- **情绪异想体系统**：每个异想体拥有独立的情绪值、出逃条件与镇压方式（ZAYIN~ALEPH 五级危险度）
- **乐队制章节推进**：完整版规划 10 支乐队，首版实现前 2 支乐队 × 2 章主线 × 2 条个人线；每支核心乐队完成对应任务后开启全员参与的 **「考验」**
- **剧情驱动，无永久 Game Over**：失败转化为资源损失与剧情分支；血量归零=崩溃退场数日

## 资源系统（脑叶式三层）

| 资源 | 层 | 用途 |
|---|---|---|
| 情感粒子 | 局内（当日能源） | 达成每日目标、结束当天 |
| 星石 | 局外（持久货币） | 设施升级、角色强化、解锁乐队 |
| 异想体点数 | 贯穿局内外 | 解锁各异想体的情报 / 剧情 / 奖励 |
